This project demonstrates the **complete workflow** of building, training, and deploying a machine learning model using **AWS SageMaker**.  
The project focuses on **real-world practices** including environment setup, data preprocessing, feature engineering, model training, and cloud deployment.  

---

## 📌 Project Workflow  

### **Step 1: Introduction & Environment Setup**  
- Overview of SageMaker, S3, EC2, and IAM roles  
- Setting up AWS environment and SageMaker instance  

### **Step 2: GitHub Integration & Data Cleaning**  
- Creating local and remote repositories with GitHub  
- Cleaning datasets using **NumPy** and **Pandas**  

### **Step 3: Exploratory Data Analysis (Part 1)**  
- Systematic dataset analysis  
- Visualization using plots, statistical measures, and hypothesis tests  

### **Step 4: Exploratory Data Analysis (Part 2)**  
- Using a custom EDA module for faster insights  
- Analyzing numeric, categorical, and date-time variables  
- Performing univariate, bivariate, and multivariate analysis  

### **Step 5: Feature Engineering & Data Preprocessing**  
- Feature engineering for different variable types  
- Creating **scikit-learn compatible custom classes and functions**  
- Using advanced scikit-learn tools:  
  - `Pipeline`  
  - `FeatureUnion`  
  - `FunctionTransformer`  
  - `ColumnTransformer`  

### **Step 6: Model Training, Tuning & Deployment**  
- Training and hyperparameter tuning of models on SageMaker  
- Using **S3 for storage** and **EC2 for computation**  
- Building a **Streamlit web app** and deploying it on the cloud  

---

## ⚙️ Prerequisites  

- Python **3.8+**  
- AWS Account with access to **SageMaker, S3, EC2, and IAM**  
- Basic knowledge of **Machine Learning concepts**
